# 微信小程序注册页验证码按钮宽度微调设计

## 背景

微信小程序邮箱注册页的“发送验证码”按钮在邮箱输入框内占宽过大，压缩了邮箱输入区域。用户要求把按钮缩短到当前视觉长度的一半左右，并确保按钮文字始终保持单行。

## 设计决定

- 只修改 `apps/wechat-miniprogram/pages/login/register-email/index.wxss`，不调整页面结构、业务状态、文案或验证码流程。
- 将按钮设为固定 `168rpx` 宽度，并以 `flex: 0 0 168rpx` 禁止其在邮箱行内被默认按钮宽度拉伸。
- 保留 `white-space: nowrap`，让“发送验证码”“再次发送”和倒计时文本始终单行显示。
- 邮箱输入框继续使用 `flex: 1` 占据剩余宽度；按钮高度、圆角、颜色和触摸区域保持不变。

## 未采用方案

- 不使用百分比宽度：窄屏设备上可能不足以容纳完整文字。
- 不使用纯内容自适应宽度：不同状态文案会导致按钮宽度跳动，无法稳定达到缩短一半的视觉目标。

## 验收标准

1. 按钮视觉长度约为用户截图中当前长度的一半。
2. “发送验证码”“再次发送”以及倒计时均不换行。
3. 邮箱输入框占据按钮以外的剩余空间，邮箱行不溢出。
4. 微信小程序 TypeScript 检查和微信开发者工具编译通过。
5. 在手机竖屏窄屏模拟器中检查注册页，无文字遮挡或横向溢出。
