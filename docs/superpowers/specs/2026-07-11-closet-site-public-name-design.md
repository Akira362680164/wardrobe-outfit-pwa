# “个人内网穿透及衣橱小站”官网命名对齐设计

## 1. 背景与目标

腾讯云 ICP 备案管理中，`zhengfangapps.cloud` 的网站互联网信息服务名称为“个人内网穿透及衣橱小站”，备案号为“鲁ICP备2026037404号-1”，运营主体为个人“方正”。现有官网使用未备案为服务名称的 “Wardora” 作为公开品牌，容易造成官网名称与备案信息不一致。

本次目标是让官网公开名称与腾讯云备案服务名称完全一致，同时保持现有 Android App 的正式产品名称“衣橱穿搭助手”，并明确网站不提供或宣传独立的公众内网穿透服务。

## 2. 已确认的命名边界

| 对象 | 统一名称 | 使用范围 |
| --- | --- | --- |
| 备案网站 | 个人内网穿透及衣橱小站 | 官网页头、首页、页脚说明、SEO、Open Graph、manifest、联系页 |
| 关联产品 | 衣橱穿搭助手 | 官网产品介绍、隐私政策、用户协议、账号注销说明、App 内法律页面 |
| 运营主体 | 方正 | 联系页、隐私政策、用户协议和备案信息 |
| manifest 短名称 | 衣橱小站 | 设备或浏览器空间不足时的短名称 |

官网所有面向访客的内容不再使用 “Wardora”。内部构建脚本名、环境变量前缀、测试目录和服务器发布目录不是公开品牌，不为本次合规命名目的做无收益重构。

## 3. 对外表达

### 3.1 首页

- 主标题：`个人内网穿透及衣橱小站`
- 副标题：`衣橱穿搭助手官方信息与合规页面`
- 产品说明：衣橱穿搭助手面向个人用户，提供衣物记录、衣橱整理、穿搭组合和穿搭计划等能力。
- 服务边界：本网站当前只提供产品介绍、隐私政策、用户协议、账号注销说明、联系渠道及备案信息，不向公众提供独立的内网穿透服务。

不得为了迎合备案服务名称而虚构内网穿透入口、套餐、账号、技术能力或服务承诺。

### 3.2 联系页

联系页分别展示：

- 网站名称：个人内网穿透及衣橱小站
- 关联产品：衣橱穿搭助手
- 服务类型：个人衣橱与穿搭管理工具的介绍及合规信息展示
- 运营主体：方正

公开联系邮箱继续使用独立配置。腾讯云域名实名认证页只显示个人 QQ 邮箱的脱敏值，在用户未明确授权公开完整邮箱前不得猜测、还原或写入官网。

### 3.3 法律页面

隐私政策、用户协议和账号注销说明中的产品主体统一称为“衣橱穿搭助手”。网站仅作为这些公开文件的发布和访问载体。邮件主题在公开邮箱配置后使用“衣橱穿搭助手账号注销”。

现有法律内容由官网和 App 复用，因此名称修正会同步进入 App 内法律页面。这是有意的一致性修正，不复制第二套容易漂移的法律文本。

### 3.4 页脚与备案

- 版权行：`© 2026 方正`
- ICP：继续展示并链接“鲁ICP备2026037404号-1”至工信部备案查询站。
- 公安备案：在取得正式公安备案号前继续显示“公安备案信息办理中”。
- 腾讯云“公安联网备案数据码”不得作为正式公安备案号展示。

## 4. 技术设计

### 4.1 集中配置

`src/lib/site-config.ts` 增加或明确以下语义字段：

- `siteName = "个人内网穿透及衣橱小站"`
- `siteShortName = "衣橱小站"`
- `productName = "衣橱穿搭助手"`
- `operatorName = "方正"`

页面、SEO 和组件从集中配置读取名称，禁止继续散落硬编码公开品牌。

### 4.2 页面与元数据

统一调整首页、页头标识、页脚、404、联系页、法律页引导文案、页面 metadata、Open Graph 和 Twitter metadata。公开 manifest 从 `/wardora.webmanifest` 改为中性路径 `/site.webmanifest`，避免公开资源地址继续携带旧名称。

### 4.3 App 边界

不修改：

- Android 应用名“衣橱穿搭助手”
- Android 包名 `com.wardrobe.outfit`
- API 域名和接口契约
- 数据库、认证、邮件发送逻辑
- 微信小程序名称和发布配置
- Caddy 站点路由、服务器发布目录及现有回滚结构

共享法律文本修正会进入后续 APK，因此实施时按项目规则递增 `package.json` 版本、重新构建固定签名 APK，并完成 Android 启动与法律页相关回归。

## 5. 验证设计

### 5.1 静态与合同检查

- 官网合同测试断言网站名、产品名、主体和 ICP 值正确。
- 扫描官网渲染 HTML、文本、metadata 和 manifest，确认不再出现大小写形式的公开 “Wardora” 文案。
- 确认不出现公安联网备案数据码、住址、手机号、证件号或其他实名认证敏感信息。
- 确认 ICP 链接仍指向 `https://beian.miit.gov.cn/`。

### 5.2 构建与视觉检查

- `npm run typecheck`
- `npm run test:logic:website`
- `npm run build`
- `npm run build:website`
- 官网 375、390、430、768、1024、1440px 响应式验证
- 人工检查长中文站名在手机页头、首页主标题和页脚中的换行与溢出

### 5.3 Android 闭环

共享法律内容进入 App 后：

- 递增版本并运行 `npm run android:apk`
- 使用固定签名 `CN=fangzheng`
- 在 Android 模拟器或真机覆盖安装
- 验证应用名仍为“衣橱穿搭助手”、启动正常、法律页面显示新名称且无 Wardora
- 采集并检查 logcat，确认无启动崩溃或严重错误

## 6. 实施与提交边界

实施在独立 worktree 内完成，保持小而完整的提交：

1. 公开网站名称、SEO、manifest 与页面文案对齐。
2. 共享法律文本、版本记录与合同测试对齐。
3. 构建、视觉验证、APK 和 Android 验证收口。

不修改生产 DNS，不部署官网，不推送远程，不提交备案变更，也不发起公安或 APP 备案流程，除非用户另行明确授权。

## 7. 完成标准

- 官网所有访客可见位置使用“个人内网穿透及衣橱小站”。
- 官网对关联产品使用“衣橱穿搭助手”，公开内容不再出现 Wardora。
- 网站明确不提供独立公众内网穿透服务。
- 运营主体、ICP 与公安备案状态真实且无敏感信息泄露。
- App 名称、包名、API 和业务功能未被网站命名调整改变。
- 网站构建、合同测试、响应式验证、APK 构建和 Android 回归均通过。
