# 衣橱穿搭助手 UI 规范 v0.3 Backlog

本文件只登记 v0.3 候选项。v0.2-final 收口期间不得实现本文件内容。

## 1. v0.3 目标边界

- 统一视觉升级。
- 强化截图回归。
- 深化 Design Tokens。
- 扩展组件状态文档。
- 不改变核心业务流程，除非另行生成独立需求文档。
