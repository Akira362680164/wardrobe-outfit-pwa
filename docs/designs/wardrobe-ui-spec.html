页面框架样式

顶部独立层

标题、返回、操作、筛选和统计属于顶部固定层。滚动内容经过其下方时由毛玻璃遮罩，不再加硬边框或额外渐变。

底部悬浮层

底部导航和底部操作栏使用圆角矩形。激活按钮与外框保持同心圆角关系，背景透明度目标 75%。

Safe Area

顶部、底部、FAB、Toast 和全屏流必须考虑 `env(safe-area-inset-*)`；录入和裁切使用 `100dvh`。

Route 矩阵

代码路由只有 15 个 `AppRouteName`。约 36 个画板状态是视觉覆盖清单，不是 route 枚举。

RouteTab类型全局创建默认返回
wardrobe_home衣橱主页面是停留 / 退出确认
garment_detail衣橱/种草来源详情否returnRoute 或来源页
outfit_home套装主页面是停留 / 退出确认

返回优先级

  1. 关闭 Lightbox。
  2. 关闭创建 Sheet、图片来源 Sheet。
  3. 关闭裁切器。

  6. 主 Tab 弹退出确认。

录入流程

用户可见只有两步；AI 识别、裁切、失败草稿、部分保存是内部子状态。

StepID标题主按钮
1select_photo选择照片下一步（AI 识别）
2confirm_params确认信息保存 N 件单品/种草
不得出现 `步骤 3 / 3`。识别失败必须进入确认页的失败草稿状态，允许手动补全和局部重新识别。部分保存必须说明未完成项不会入库。

系统状态

状态UI 规则
auth_initializing / unauthenticated登录前由 `AuthGate` 管理；提供登录、注册、协议/隐私入口。
workspace_loading / workspace_error工作区加载失败用 `OnlinePageError`，必须提供重试。
sync_refreshing / sync_refresh_error页面内轻提示或 `OnlineInlineNotice`，保留当前数据。
camera_permission_denied明确提示前往系统设置开启，不静默失败。
ai_key_missing引导前往设置页配置 MiniMax Key。
diagnostic_uploading/success/failed诊断上传有描述、创建工单、上传、成功/失败；错误码可读。
