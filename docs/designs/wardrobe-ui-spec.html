设置
1. 状态栏固定在手机顶部，高于背景内容。
2. 顶部毛玻璃承载标题、返回、关闭、筛选和固定统计。
3. 滚动内容区从顶部层下方开始，滚动经过顶部时被毛玻璃遮住。
4. 底部浮层导航或操作栏均为悬浮圆角矩形，不贴屏幕边缘。

通知 Toast

Toast 是悬浮通知，不参与文档流。首页样例宽度与底部菜单一致，层级高于滚动内容、加号和底部菜单。

结构

  • 左侧状态图标。
  • 中间主文案和辅助文案。
  • 右侧关闭图标。
  • 左侧 3px 状态色条。

视觉参数

  • 背景：rgba(255,255,252,0.75)
  • 模糊：blur(30px)
  • 圆角：18px
  • 左右边距：与底部菜单一致

验收清单

  • 只保留竖向 3:4 版本。
  • 所有页面顶部都有独立毛玻璃层。
  • 顶部下方没有硬边框和多余渐变区。
  • 底部导航是悬浮圆角矩形。
  • 底部导航激活项不是圆形。
  • 一级卡片圆角统一为 28px。
  • 卡片内图片与外卡片保持同心圆角。
  • 筛选标签没有黑色阴影区。
  • 空操作位不显示白色空框。
  • 设置图标必须是齿轮。
  • 所有主图、缩略图、裁切默认框按 3:4。
  • 单品录入流程是 2 步。
  • 颜色使用色卡展示。
  • 温度使用温度条展示。
  • 详情页名称和属性不放进卡片。
  • Toast 宽度与底部菜单一致，悬浮于所有内容之上。
