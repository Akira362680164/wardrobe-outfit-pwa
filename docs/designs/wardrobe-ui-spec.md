# 衣橱穿搭助手 UI 规范说明（草案）

版本：v0.1  
依据：`/Users/fangzheng/Desktop/wardrobe-ui-prototype/index.html`  
适用范围：当前本地 HTML 原型的竖向 3:4 UI  
不包含：弹窗、底部抽屉、横屏版、2:3 / 3:2 / 4:3 旧版

## 1. 设计目标

本规范用于统一衣橱穿搭助手的移动端 UI 表现，让后续页面补齐、代码实现和视觉走查有固定标准。

核心目标：

- 手机优先，只保留竖屏 3:4 图片展示比例。
- 页面第一屏直接展示可用功能，不做营销式页面。
- 首页、单品、套装、种草、设置使用同一套组件语言。
- 所有页面顶部使用独立毛玻璃层，滚动内容经过顶部时被遮罩。
- 一级卡片、二级卡片、图片、按钮、底部菜单遵守同心圆角关系。
- 图标优先使用明确含义的符号，不用文字代替图标。

## 4. 圆角与同心关系

当前 UI 的圆角不是简单“同一个半径”，而是按外框和内层间距形成同心圆角。

| 对象 | 半径 | 规则 |
| --- | --- | --- |
| 一级卡片 | 28px | 页面主要卡片统一使用 |
| 一级卡片内边距 | 10px 或 16px | 图片类卡片优先 10px |
| 卡片内图片 | 18px | `28px - 10px` |
| 普通控件 | 14px | 顶部按钮、筛选、输入框、二级按钮 |
| 底部菜单外框 | 26px | 悬浮毛玻璃菜单 |
| 底部菜单内边距 | 8px | 外框和按钮之间 |
| 底部菜单选中按钮 | 18px | `26px - 8px` |
| 缩略图 | 12px | 队列缩略图、胶片缩略图 |

判断标准：

- 外框和内层按钮的弧度要像同一组同心圆。
- 图片放在卡片内时，图片圆角必须小于卡片圆角。
- 不允许外层大圆角、内层完全圆形的混搭，除非是明确的悬浮加号。

## 5. 毛玻璃层

### 顶部毛玻璃

所有页面顶部都使用独立毛玻璃层。

参数：

- 背景：`rgba(251,251,248,0.75)`
- 模糊：`blur(30px)`
- 饱和：`saturate(1.5)`
- 层级：高于滚动内容
- 底部：不加硬边框，不加额外渐变过渡区

顶部内容包含：

- 状态栏下方的页面标题区。
- 返回 / 关闭 / 页面操作图标。
- 当前页面需要固定展示的筛选、统计、分段控件。

### 底部毛玻璃

底部导航和底部操作栏使用同一类毛玻璃。

参数：

- 背景：`rgba(255,255,252,0.75)` 或 `rgba(251,251,248,0.75)`
- 模糊：`blur(30px)`
- 饱和：`saturate(1.45)`
- 形态：悬浮圆角矩形，不贴死屏幕边缘

底部导航：

- 固定 4 项：衣橱、套装、种草、设置。
- 激活项使用圆角矩形，不使用圆形按钮。
- 图标和文字垂直排列。
- 设置图标必须使用齿轮。

## 6. 页面结构

每个页面由以下层组成：

1. 手机外框。
2. 状态栏。
3. 顶部独立毛玻璃层。
4. 可滚动内容区。
5. 可选悬浮加号。
6. 可选底部操作栏或底部导航。

内容区规则：

- 内容从顶部毛玻璃下方开始。
- 滚动时内容可以进入顶部层下方，但必须被毛玻璃遮住。
- 带底部导航或底部操作栏的页面，内容底部留出安全距离。
- 页面不要按行或按列机械铺开，画板按真实页面跳转关系展开。

## 8. 关键组件规范

### 8.1 顶部组件

首页顶部包含：

- 衣橱范围选择。
- 搜索按钮。
- 统计按钮。
- AI 按钮。
- 小号数据统计。
- 横向筛选标签。

普通子页面顶部包含：

- 左侧返回。
- 居中标题。
- 标题下方小字说明。
- 右侧关闭或操作图标，没有操作时不显示白色空框。
- 如有步骤，步骤文案显示在标题下方小字，不单独做一整排步骤标签。

### 8.2 筛选标签

筛选标签使用圆角矩形。

- 高度：约 30px。
- 圆角：12px。
- 选中背景：Denim。
- 未选中背景：Surface。
- 不允许在标签后面出现黑色阴影区。

### 8.3 一级卡片

一级卡片用于承载页面主要内容。

- 圆角：28px。
- 背景：`rgba(255,255,252,0.92)`。
- 边框：Line。
- 阴影：轻量阴影。
- 不嵌套另一个一级卡片。

适用对象：

- 诊断提示卡。
- 表单分组。
- 详情属性组。
- 周历。
- 列表分组。

### 8.4 二级卡片

二级卡片用于一级卡片内部的操作入口或字段块。

- 圆角按同心规则小于一级卡片。
- 背景可以更轻，不抢一级卡片层级。
- 不独立漂浮到页面层级。

### 8.5 衣物卡片

衣物卡片由图片、名称、属性、色点组成。

要求：

- 卡片固定宽高规则，不按图片内容拉伸。
- 图片比例固定 3:4。
- 图片圆角与卡片圆角保持同心关系。
- 名称最多两行，属性用小字。
- 色彩展示用圆形色点。

### 8.6 详情页主图与胶片栏

单品、套装、种草详情使用同一框架：

1. 3:4 主图。
2. 横向胶片缩略图。
3. 裸露在底层上的名称和属性，不放进卡片。
4. 详情页标签。
5. 属性卡片。

添加灵感图或商品图：

- 不作为单独的大卡片。
- 放在主图后的胶片栏中。

### 8.7 颜色组件

颜色必须按生产逻辑展示，不用纯文字。

详情页颜色展示：

- 主色一行。
- 辅助色一行。
- 每个颜色包含色点和颜色名。

编辑页颜色展示：

- 颜色模式和颜色在同一张一级卡片。
- 颜色模式：单主色、拼色、主辅色。
- 色卡区分常用色和已选色。
- 色卡使用色点加名称，不用大块纯色按钮。

### 8.8 温度组件

温度不用纯文本字段展示。

展示方式：

- 标题：适穿温度。
- 数值：如 `18℃ ~ 28℃`。
- 横向温度条。
- 用双手柄表示温度范围。

### 8.9 周历组件

套装首页上方使用可横向滑动周历。

周历内容：

- 周几。
- 日期。
- 当天套装缩略图。
- 当前选中日期状态。

不使用单独的“本周计划”大卡片代替周历。

### 8.10 裁切/旋转页

裁切页顶部不显示进度条。

工具区包含：

- 自由。
- 3:4。
- 左转 90°。
- 右转 90°。
- 重置。

默认裁切框按 3:4 竖向比例。

### 8.11 图片选择队列

录入流程中的缩略图队列必须使用圆角矩形。

要求：

- 不使用圆形缩略图。
- 当前选中项有 Denim 边框。
- 点击缩略图后出现裁切/旋转、删除等就近操作。
- 选择照片页内容应尽量在一屏内展示，不让核心操作被滚动压到屏外。

### 8.12 Toast 通知

Toast 用于即时反馈，不参与页面文档流，不挤压内容。

结构：

- 左侧状态图标。
- 中间主文案和辅助文案。
- 右侧关闭图标。
- 左侧 3px 状态色条。

视觉：

- 背景：`rgba(255,255,252,0.75)`。
- 模糊：`blur(30px)`。
- 饱和：`saturate(1.45)`。
- 圆角：18px，跟底部菜单内层按钮保持同心关系。
- 成功状态使用 Moss，信息状态使用 Denim，错误状态使用红色。

首页样例：

- 放在底部导航上方。
- 宽度与底部操作栏 / 底部菜单一致，左右边距同为 16px。
- 悬浮于页面所有内容之上，层级高于滚动内容、悬浮加号和底部菜单。
- 不遮挡顶部毛玻璃层。

## 9. 业务模块模板

### 衣橱首页

默认不展示 AI 衣橱诊断卡。  
AI 诊断卡只有点击右上角 AI 按钮后才出现。

首页默认结构：

1. 顶部工具和筛选。
2. 瀑布流衣物卡片。
3. 悬浮加号。
4. 底部导航。

### 单品详情

单品、套装、种草详情共用详情框架。

名称和属性直接放在页面底层上，不放进卡片。

### 单品录入

当前流程为 2 步：

1. 选择照片。
2. 确认信息。

步骤信息放在页面标题下方小字中。  
确认页保留重新识别入口，位置跟随识别结果区域，不放错到无关信息块。

### 套装首页

顶部展示可滑动周历和套装缩略图。  
套装卡片进入套装详情，套装名称不放在卡片式信息块中。

### 种草

种草详情使用和单品详情一致的框架。  
商品图、灵感图放在主图后面的胶片栏。  
加入衣橱必须有确认页面。

### 设置

设置页作为圆角和卡片标准参考页面。  
其他页面的一级卡片、二级卡片、按钮圆角应向设置页统一。

## 10. 图标规范

底部导航：

- 衣橱：衣服。
- 套装：叠层。
- 种草：购物袋。
- 设置：齿轮。

常用操作：

- 搜索：放大镜。
- 统计：柱状图。
- AI：星光。
- 返回：左箭头。
- 关闭：叉号。
- 拍照：相机。
- 从图库选择：图片。
- 裁切/旋转：剪刀或旋转。
- 删除：垃圾桶。
- 修改密码：钥匙。

要求：

- 有明确图标时不用文字替代。
- 不使用含义不匹配的图标。
- 空操作位不显示白框。

## 11. 文案规范

文案原则：

- 标题短，动作明确。
- 统计数据用小字，不做大号仪表盘。
- 步骤数量必须与真实流程一致。
- 操作按钮说清下一步会发生什么。
- 不在页面内解释 UI 用法、设计意图或快捷键。

示例：

- `步骤 1 / 2 · 选择照片`
- `下一步（AI 识别）`
- `保存 3 件单品`
- `重新识别`
- `加入衣橱`

## 12. 状态规范

必须覆盖的状态：

- 默认。
- 选中。
- 待确认。
- 已识别。
- 已保存。
- 空内容。
- 错误或失败。
- 正在处理。

视觉要求：

- 选中状态优先使用 Denim。
- AI 或识别状态可以使用 Clay 或 Denim，但不要混用导致含义不清。
- 待确认字段需要在表单内突出，但不能破坏整体布局。

## 13. 验收检查清单

每次新增或修改页面时检查：

- 是否只保留竖向 3:4 版本。
- 是否没有横屏专用设计。
- 是否使用顶部独立毛玻璃层。
- 顶部下方是否没有硬边框或多余渐变区。
- 底部导航是否为悬浮毛玻璃圆角矩形。
- 底部导航激活项是否为圆角矩形。
- 所有一级卡片圆角是否统一。
- 卡片内图片是否与外卡片保持同心圆角。
- 筛选标签是否没有黑色阴影区。
- 空操作位是否没有白色空框。
- Toast 是否为毛玻璃浮层，且不和底部导航、加号重叠。
- 图标是否符合含义。
- 所有衣物、种草、套装主图是否为 3:4。
- 录入流程是否为 2 步。
- 选择照片页核心内容是否一屏内可见。
- 颜色是否用色卡展示。
- 温度是否用温度条展示。
- 名称和属性在详情页是否放在底层上，而不是卡片里。
- 周计划是否使用可滑动周历和套装缩略图。
- 页面画板是否按页面跳转关系展开。
